# تقرير الاختبارات والمراجعة البصرية — بَرْدُ اليقين

**تاريخ التشغيل:** ١٣ سبتمبر ٢٠٢٦ · **البيئة:** Node.js 22 · Chromium (Playwright)
**الحالة:** بعد تنفيذ الإصلاحات التسعة واستبدال الأنماط بمسارين وإضافة ٣٨ تفاعلًا.

## الخلاصة

| الطبقة | الأداة | العدد | النتيجة |
|---|---|---:|---|
| منطق خالص (بلا متصفح) | `tests/run.mjs` | ٥٥ | **٥٥ ✅ / ٠ ❌** |
| واجهة في متصفح حقيقي | `tests/e2e.mjs` | ٥٧ | **٥٧ ✅ / ٠ ❌** |
| فحص بصريّ آليّ | `tests/visual-audit.mjs` | ٦٧٢ فحصًا | **٠ خطأ · ٠ تنبيه** |
| قياس تجربة ٦ فئات | `tests/persona-walkthrough.mjs` | ٦ فئات | لا عائق |
| الدليل البصري | `tests/screenshots.mjs` | ١٠٣ صورة | — |

**المجموع: ١١٢ اختبارًا، كلّها ناجحة**، و٦٧٢ فحصًا بصريًّا بلا خطأ ولا تنبيه.

**ما لا يُقاس آليًّا:** اسم البرنامج في الشاشة الافتتاحية (`.hero__name`) مرسوم
بتدرّج لونيّ (`background-clip: text`)، فلا تُقاس نسبة تباينه بقراءة `color`
— يُراجَع بصريًّا في `docs/screenshots/*-01-splash.png`. وهذا مُعلَن في مخرجات
الأداة نفسها تحت «لم يُقَس آليًّا».

## ٥) ما يغطّيه الاختبار من الضوابط الشرعية

| الضابط | الاختبار |
|---|---|
| لا قراءة آلية للقرآن | `ضابط شرعي: لا قراءة آلية للقرآن` + `كل بطاقة قرآنية في المحتوى محميّة` (منطق)، و`زر الاستماع معطّل للآيات وسببه ظاهر في الواجهة` (واجهة) |
| لا إكمال آية كتابةً ولا شرطًا للتقدّم | `لا يُطلب إكمال نصّ قرآني كتابةً، ولا يُشترط لتقدّم المتعلّم` (منطق) |
| كل نصّ قرآني موسوم للمراجعة وله مرجع | `كل نصّ قرآني معلَّم needsReview وله مرجع` |
| كل صياغة مستحدثة تدخل المراجعة ولا تُعتمد تلقائيًّا | `كل تفاعل مستحدث موسوم authored ومُدرَج في المراجعة ومنسوب لصفحة` |
| المحتوى الشرعي لا يختلف بين المسارين | `المراجعة السريعة لا تُنقص من الأسئلة شيئًا` + `المراجعة السريعة تُبقي نصوص الكتاب متاحة` |
| قائمة المراجعة تطابق المحتوى | `قائمة المراجعة تطابق العناصر المعلَّمة` |
| تمييز الأصل عن الصياغة المساعدة في الواجهة | `النصّ الشرعي مميّز عن الصياغة التعليمية المساعدة` |
