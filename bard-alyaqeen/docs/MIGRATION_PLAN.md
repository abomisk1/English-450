## ٢) طريقة النقل الموصى بها: `git subtree split`

تحتفظ بسجلّ Git الخاصّ بالمجلد وحده، وتُسقط تاريخ `English-450` كاملًا،
فلا يحمل المستودع الجديد أي أثر لمشروع آخر.

```bash
# داخل نسخة English-450، على الفرع الحالي
git checkout claude/bard-al-yaqeen-program-jckzr0

# ١) استخراج تاريخ المجلد وحده في فرع مؤقّت
git subtree split --prefix=bard-alyaqeen -b bay-extract
#    النتيجة: فرع bay-extract جذره مجلد المشروع، بلا ملفات English-450.

# ٢) إنشاء المستودع الجديد محليًّا
mkdir ../bard-al-yaqeen && cd ../bard-al-yaqeen
git init -b main
git pull ../English-450 bay-extract

# ٣) التحقّق قبل الربط بأي مستودع بعيد
ls                      # يجب أن يظهر index.html و content/ و js/ في الجذر
git log --oneline       # يجب أن يظهر التزام «إضافة برنامج بَرْدُ اليقين»
git ls-files | wc -l    # يجب أن يساوي ١١٠
```

### لماذا لا `git filter-repo`؟
لأن المشروع في التزام واحد داخل مجلد واحد، فـ `subtree split` أبسط وأدقّ ولا
يحتاج أداة خارجية. و`filter-repo` مناسب لو كان التاريخ متشابكًا مع ملفات أخرى.

### لماذا لا مجرّد نسخ الملفات؟
لأنه يُسقط سجلّ Git ورسالة الالتزام التي توثّق طريقة استخراج نصّ الكتاب
والقرارات الشرعية. النسخ خيار احتياطي إن لم تُرد سجلًّا.

## ٣) التحقّق بعد النقل — قائمة فحص إلزامية

تُنفَّذ داخل المستودع الجديد **قبل** أي دفع إلى مستودع بعيد:

```bash
python3 scripts/build_content.py     # يجب: units=7 lessons=66 cards=192 interactions=167 quiz=148 tasks=35 needsReview=304
python3 scripts/audit_counts.py      # يجب: بلا تحذيرات
python3 scripts/export_review.py     # يجب: 304 عنصرًا
python3 scripts/build_docs.py
python3 scripts/audit_quran.py --check  # يجب: ٠ مخالفة

npm i -D playwright@1.49.1
node scripts/serve.mjs &
node tests/run.mjs                   # يجب: ٥٨ ناجح، ٠ فاشل
node tests/e2e.mjs                   # يجب: ٦٢ ناجح، ٠ فاشل
node tests/visual-audit.mjs          # يجب: ٠ خطأ، ٠ تنبيه
node tests/screenshots.mjs
```

| الفحص | القيمة المتوقَّعة |
|---|---|
| `git ls-files \| wc -l` | ١٨٠ |
| `git log --oneline \| wc -l` | ١ |
| محتوى `content/units/` | ٧ ملفات |
| `content/needs-review.json` → `count` | ٣٠٤ |
| `docs/screenshots/*.png` | ١٢٧ (+ `README.md`) |
| `assets/fonts/*.woff2` | ٤ |
| اختبارات المنطق | ٥٨ / ٥٨ |
| اختبارات الواجهة | ٦٢ / ٦٢ |
| الفحص البصري | ٧٠٢ فحصًا · ٠ خطأ |
| تدقيق النصّ القرآني | ٢١٧١ فحصًا · ٠ مخالفة |
| فتح `index.html` عبر خادم محلي | الشاشة الافتتاحية تظهر واسم الكتاب ومؤلفه |

**لا يُحذف المجلد من `English-450` إلا بعد اجتياز هذه القائمة كاملة**، ويُفضَّل
إبقاء الفرع الحالي كما هو نسخةً احتياطية شهرًا على الأقل.

| الطبقة | المطلوب |
