# نص ملخص «زاد العباد» (ص٤–٨) للقارئ

- `extract_summary.py <summary.pdf> <out.json>`: يستخرج النص من طبقة نص ملف PDF الأصلي (بلا تعديل للملف)، ويحتفظ برقم صفحة الملخص لكل فقرة وبصمة الملف وإصداره (`zad-sum-1`). الآيات تُستبدل بنص مجمع الملك فهد (الإملائي) المطابَق حرفيًا للمقطع المقتبس (يحتاج `/tmp/vv/kfgqpc.json`).
- `crosscheck.py <summary.pdf> <json>`: مطابقة مستقلة لحروف كل صفحة مع pdftotext.
- `zad-p4-8.json`: النص المنسّق (كتل: banner, h1, topic, evidence, bullet, note, review) مع المباحث T1–T9 والتصحيحات الموثّقة وسجل مطابقة الآيات.
- `build_match_report.py`: يولّد `../match-report.html`.
- ملف PDF الأصلي غير مدرج في المستودع. ولا تُحوَّل بقية الصفحات قبل اعتماد طريقة العرض.
