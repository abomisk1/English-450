# نظام الإحصائيات المجهولة — دليل الإعداد

نظام بسيط وموثوق لقياس مدى استفادة المستخدمين من **English 450**، **دون تسجيل دخول
للمستخدمين ودون أي معلومات شخصية**. يعتمد على مشروع **Supabase** مجاني.

## ماذا يُجمَع؟ (وماذا لا يُجمَع)

- **يُجمَع:** معرّف عشوائي مجهول (UUID) لكل جهاز، وقت أول ظهور وآخر ظهور، والمستويات
  التي أتقنها المستخدم، وهل أكمل البرنامج (450/450).
- **لا يُجمَع إطلاقًا:** الاسم، البريد، الجوال، أي معرّف شخصي، أو محتوى التقدّم نفسه.
- المعرّف يُحفظ محليًا في مفتاح **منفصل** (`english450:anon:v1`) ولا يمسّ بيانات التقدّم
  (`english450:progress:v1`).
- **«الإكمال» = الإتقان الكامل:** إكمال المستوى = إتقان كل عناصره، وإكمال البرنامج =
  إتقان 450/450 (نفس معيار شاشة الإكمال في التطبيق).

> النظام **اختياري**: إن تركت الإعداد فارغًا، يعمل التطبيق بالكامل كالمعتاد بلا أي أثر.

## خطوات الإعداد

### 1) أنشئ مشروع Supabase مجاني
- ادخل https://supabase.com → New project (الخطة المجانية كافية تمامًا).
- اختر اسمًا وكلمة مرور قاعدة البيانات واحفظها.

### 2) شغّل مخطّط قاعدة البيانات
- من المشروع: **SQL Editor → New query**.
- الصق كامل محتوى الملف [`supabase/schema.sql`](../supabase/schema.sql) ثم **Run**.
- ينشئ هذا: جدولين، تفعيل RLS (بلا وصول مباشر)، ودوال الكتابة/القراءة وصلاحياتها.

### 3) اربط التطبيق بالمشروع (مفاتيح عامة فقط)
- من Supabase: **Project Settings → API**، وانسخ:
  - **Project URL** → `SUPABASE_URL`
  - **anon public** key → `SUPABASE_ANON_KEY`
- الصقهما في [`js/config/analytics.config.js`](../js/config/analytics.config.js).

> ✅ هذان القيمتان **عامّتان وآمنتان** للنشر في الواجهة و GitHub. المفتاح `anon`
> مُصمَّم للمتصفّح ومحمي بصلاحيات RLS.
> ⛔ **لا تضع مفتاح `service_role` إطلاقًا** في الكود أو GitHub — يبقى في لوحة Supabase فقط.

### 4) أنشئ حساب المشرف (للوحة الإحصائيات فقط)
- من Supabase: **Authentication → Users → Add user** — أدخل بريدًا وكلمة مرور،
  وفعّل «Auto Confirm User».
- **أوقِف التسجيل العام** حتى لا يُنشئ أحد حسابًا: **Authentication → Providers → Email**
  وعطّل «Allow new users to sign up» (أو من **Authentication → Sign In / Providers**).
  بهذا يبقى حسابك أنت الوحيد القادر على فتح اللوحة.

### 5) افتح لوحة الإحصائيات
- بعد نشر الموقع على GitHub Pages، افتح المسار `‎/admin/` (مثال:
  `https://<user>.github.io/<repo>/admin/`).
- سجّل الدخول ببريد المشرف وكلمة مروره. لا يوجد أي رابط للوحة داخل التطبيق العام.

## الأمان والخصوصية

- **RLS مفعّل بلا سياسات وصول مباشرة** ⇒ لا يستطيع أحد (anon أو مُصادَق) قراءة الجداول
  أو الكتابة فيها مباشرة.
- **الكتابة** تتمّ فقط عبر دوال `SECURITY DEFINER` بمنطق ثابت، ومنع تكرار الاحتساب
  مضمون بمفاتيح الجداول (`PRIMARY KEY`) وعبارات `on conflict`.
- **القراءة (اللوحة)** عبر دالة `get_stats()` المصرّح بها لدور **authenticated فقط**،
  وتُعيد أرقامًا مجمّعة لا صفوفًا خام ⇒ المستخدم العادي لا يرى اللوحة ولا البيانات الخام.
- **معرّف عشوائي فقط، بلا PII** — متوافق مع الخصوصية.
- **خطر منخفض مقبول:** يمكن نظريًا استدعاء دوال الكتابة لتضخيم الأرقام (طبيعة أي رصد
  بلا تسجيل دخول). لتطبيق تعليمي صغير هذا مقبول؛ يمكن لاحقًا إضافة حدّ معدّل عند الحاجة.

## التكلفة

مجاني بالكامل على الطبقة المجانية لـ Supabase (قاعدة 500MB وطلبات وافية لهذا الحجم).
قد تُوقَف مشاريع الطبقة المجانية مؤقتًا بعد خمول طويل وتُستأنف تلقائيًا — دون أثر على
التطبيق لأن الرصد fire-and-forget.

## تعطيل النظام

اترك `SUPABASE_URL` و`SUPABASE_ANON_KEY` فارغين في `analytics.config.js` — يتعطّل
النظام تلقائيًا (no-op) ويعمل التطبيق كالمعتاد.
