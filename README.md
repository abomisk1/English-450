# English 450

تطبيق ويب مجاني وسهل جدًا للناطقين بالعربية، يساعد المبتدئ على بناء قاعدة عملية في
اللغة الإنجليزية عبر إتقان **أهم 350 كلمة** و**أهم 100 جملة/عبارة** مستخدمة في الحياة اليومية —
من خلال تجربة تعليمية تفاعلية ذكية وممتعة، لا مجرد بطاقات حفظ.

> ✅ المحتوى مكتمل: **350 كلمة** و**100 جملة** عملية، مرتّبة تدريجيًا من الأسهل إلى الأصعب،
> بلا تكرار، مع أمثلة ونطق لكل عنصر.

---

## ✨ ماذا يقدّم التطبيق؟

- **واجهة عربية بالكامل** بلغة سهلة، مع دعم كامل لـ RTL (العربية) وLTR (الإنجليزية).
- **Mobile-First** — تصميم هادئ واحترافي ممتاز على الجوال أولًا ثم الكمبيوتر.
- **جلسة يومية قصيرة** (٥ إلى ١٠ دقائق): تعلّم عناصر جديدة → تمارين → مراجعة → نتيجة.
- **٦ أنواع تمارين تفاعلية** مع تنويع محسوب (Interleaving):
  1. اختر المعنى العربي الصحيح.
  2. اختر الكلمة الإنجليزية للمعنى.
  3. استمع واختر ما سمعت.
  4. أكمل الفراغ الناقص.
  5. رتّب كلمات الجملة.
  6. موقف واختر العبارة المناسبة.
- **النطق الصوتي 🔊** لكل كلمة وجملة ومثال (عبر Web Speech API — مجاني وبلا مفاتيح).
- **مراجعة متباعدة ذكية** (Spaced Repetition) تعيد العناصر في الوقت المناسب.
- **إتقان قبل الإنهاء**: أي إجابة خاطئة يُعاد سؤالها لاحقًا في الجلسة نفسها، ولا تكتمل
  الجلسة (شاشة النتيجة) حتى تُصحَّح كل الأخطاء.
- **تغذية راجعة فورية** ولطيفة بلا عقاب مبالغ فيه.
- **حفظ التقدم محليًا** (LocalStorage) — يبقى بعد إغلاق الصفحة، بلا حساب ولا تسجيل دخول.
- **لوحة تقدّم** واضحة: الكلمات/الجمل المكتسبة، نسبة الإتقان، المراجعات، الاستمرارية، الإنجازات.
- **تحفيز خفيف وذكي**: نقاط، استمرارية (Streak)، إنجازات، شريط تقدم — بلا إفراط.

## 🧠 فلسفة التعلّم

مبنيّة على مبادئ تعليمية فعّالة، مطبّقة بشكل طبيعي غير أكاديمي للمستخدم:
Active Recall · Spaced Repetition · Retrieval Practice · Contextual Learning ·
Microlearning · Interleaving · Immediate Feedback · Mastery Learning.

الهدف الحقيقي هو **الفهم والتذكّر والاسترجاع والاستخدام** — وليس الأرقام بحد ذاتها.

## 🚀 كيف تشغّل التطبيق؟

التطبيق **موقع ثابت (static) بلا خطوة بناء وبلا اعتماديات** — يكفي تشغيل خادم ملفات بسيط
(لأن المتصفح يمنع وحدات ES من العمل عبر `file://`).

اختر أيّ طريقة:

```bash
# 1) عبر npm (يشغّل خادمًا محليًا ويفتح المتصفح)
npm start

# 2) عبر Python (متوفّر على أغلب الأنظمة)
python3 -m http.server 8080
# ثم افتح: http://localhost:8080

# 3) عبر npx مباشرة
npx --yes http-server . -p 8080 -c-1 -o
```

ثم افتح المتصفح على `http://localhost:8080`.

> ملاحظة: عند فتح `index.html` مباشرة بنقرة مزدوجة قد تمنع بعض المتصفحات وحدات ES —
> لذلك استخدم أحد الخوادم أعلاه.

## 🗂️ بنية المشروع

```
index.html            # نقطة الدخول (RTL، يحمّل الوحدات)
styles.css            # نظام التصميم (Design tokens + كل الأنماط)
js/
  app.js              # الموجّه + شريط التنقل السفلي
  store.js            # مخزن الحالة (observable) + الإحصاءات المشتقّة
  data/               # المحتوى (350 كلمة + 100 جملة) + التصنيف الموحّد
    words.js          # مُولّد آليًا — لا يُحرّر يدويًا
    phrases.js        # مُولّد آليًا — لا يُحرّر يدويًا
    index.js
  lib/                # منطق خالٍ من الواجهة (قابل للاختبار والاستبدال)
    srs.js            # المراجعة المتباعدة
    session.js        # بناء الجلسة
    exercises.js      # مولّدات التمارين
    speech.js         # طبقة النطق (Web Speech API)
    storage.js        # طبقة التخزين (LocalStorage)
    shuffle.js
  ui/                 # طبقة العرض (Vanilla DOM)
    dom.js            # مساعد h() + أيقونات
    widgets.js        # عناصر مشتركة (زر نطق، حلقة تقدم، تغذية راجعة...)
    home.js
    progress.js
    session.js
content-src/          # مصدر المحتوى المختصر (يُحرَّر يدويًا)
  words-src.mjs
  phrases-src.mjs
scripts/
  generate-content.mjs  # يتحقق من عدم التكرار، يرتّب حسب الصعوبة، ويولّد js/data/*.js
PROJECT_PLAN.md       # الخطة والمعمارية والقرارات
```

### تعديل المحتوى أو توسيعه

المحتوى في `js/data/words.js` و`js/data/phrases.js` **مُولّد آليًا** — لا تُحرّره مباشرة.
بدلًا من ذلك عدّل المصدر في `content-src/` ثم أعد التوليد:

```bash
node scripts/generate-content.mjs          # تقرير فقط (عدد، تكرارات، توزيع الصعوبة)
node scripts/generate-content.mjs --write   # يتحقق ويكتب js/data/*.js
```

يرفض المولّد الكتابة إذا وجد أي تكرار أو حقل ناقص، ويرتّب العناصر تلقائيًا من الأسهل إلى الأصعب.
